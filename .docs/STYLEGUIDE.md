LUẬT THIẾT KẾ: EN-LEARNING
1. Typography (Font chữ)
Font chữ chủ đạo: Inter (sans-serif).
Cỡ chữ:
Tiêu đề trang: 28px
Tiêu đề Card: 18px - 20px
Text thông thường: 14px
Text phụ: 12px

2. Bảng màu & Điểm nhấn (Color Palette)
Primary Color: #008FD5 — nút chính, link, menu đang chọn.
Primary Light: #E6F4FA — nền mục đang chọn.
Page Background: #F7F9FF.
Card Background: #FFFFFF.
Border Color: #E5E8EE.
Text Color: #181C20.
Small Text Color: #64748B.
Success Color: #16A34A.

3. Trải nghiệm người dùng (UX Constraints)
Sử dụng React + TypeScript + Ant Design.
Layout Desktop gồm Sidebar trái, Top Header và grid 12 cột.
Card bo góc 10px - 12px, viền mảnh, bóng nhẹ.
Mỗi màn hình chỉ có một nút chính màu Primary.
Form phải validate và hiển thị lỗi ngay gần ô nhập.
Hiển thị Toast khi thao tác thành công hoặc thất bại.
Có trạng thái Loading, Empty và Error cho dữ liệu API.
Responsive: Sidebar thu gọn trên tablet và thành menu trên mobile.

4. Phong cách cần tránh
Không dùng hoạt hình trẻ con, gradient mạnh, glassmorphism hoặc quá nhiều icon.
Không dùng chữ quá lớn hoặc nhồi quá nhiều Card/Biểu đồ trên Dashboard.
